# LLM Provider Package

The `llm` package defines the interfaces and provides implementations for Large Language Models (LLMs) used for both chat completions and generating vector embeddings.

## Interface: `Provider`

All LLM integrations must satisfy the `Provider` interface:

```go
type Provider interface {
    // Embed generates a vector representation of the given text.
    Embed(ctx context.Context, text string) ([]float64, error)
    
    // Chat generates a response based on the provided prompt and context.
    Chat(ctx context.Context, prompt string) (string, error)
    
    // GetEmbeddingDimension returns the length of the vector generated by Embed.
    GetEmbeddingDimension() int32
}
```

## Supported Providers

### Ollama (Local)
The default provider for RagCode. It interacts with a local Ollama instance via its REST API. It is recommended to use models like `qwen2.5-coder` for chat and `qwen3-embedding` for high-quality representations.

### OpenAI (Cloud)
Can be configured for projects requiring high-end reasoning or larger embedding dimensions using models like `gpt-4o` and `text-embedding-3-small/large`.

## Factory Pattern

Providers are typically initialized via a factory system based on the configuration:

```go
p, err := llm.NewProvider(cfg.LLM)
```
